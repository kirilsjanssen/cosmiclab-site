# PixelGift Games website v0.1

Автономный многостраничный сайт сервиса персонализированных ретро-игр для Android. Сайт создан для будущей ручной публикации по адресу `https://cosmiclabindicators.com/pixelgift/` и не требует сборщика, Node.js, базы данных или серверного кода.

## Страницы

- `index.html` — главная и коммерческая презентация.
- `games.html` — каталог игровых шаблонов.
- `customize.html` — шестишаговый конструктор демонстрационной заявки.
- `how-it-works.html` — этапы работы, DEMO и установка APK.
- `faq.html` — вопросы о фотографиях, персонажах, DEMO, оплате и возвратах.

## Запуск локально

Из папки `PixelGift_Website_v0.1`:

```powershell
py -m http.server 8080 --bind 127.0.0.1
```

Откройте `http://127.0.0.1:8080/`. Локальный HTTP-сервер нужен для корректной проверки сайта в условиях, близких к обычному статическому хостингу.

## Конфигурация

Цены, лимиты персонажей и статусы игр находятся в `assets/js/config.js`. Тексты RU/DE/EN находятся в отдельных словарях `assets/i18n/ru.js`, `de.js` и `en.js`.

## Приватность конструктора

Фотографии проверяются в браузере (JPG/PNG/WebP, до 8 MB), показываются через локальные `blob:` URL и удаляются из памяти при удалении пользователем или закрытии вкладки. Форма не выполняет сетевой запрос, не сохраняет персональные данные в `localStorage` и не отправляет заявку. В `localStorage` хранится только выбранный язык интерфейса.

## Графика

Шесть оригинальных сцен созданы через Luma Agents API моделью `uni-1-max`. В публичной части используются адаптивные WebP, также сохранены AVIF-варианты. Исходники, технические метаданные и точные промпты находятся в `source_assets/` и `docs/LUMA_PROMPTS.md`; они не требуются на хостинге.

## Ограничения v0.1

- Приём заказов и отправка формы отключены.
- Оплата, аккаунты, лицензии и выдача APK не реализованы.
- Автоматическая генерация спрайта из фотографии не заявляется.
- Pixel Commando и Pixel Action обозначены как будущие шаблоны.
- Цены и состав пакетов предварительные.

Сценарий ручной публикации описан в `DEPLOY.md`, результаты проверок — в `QA_REPORT.md`.
