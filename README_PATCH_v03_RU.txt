GROMVEX AI MOVIE STUDIO — PATCH v03
===================================

Что добавлено в v03
-------------------
1. Скрепка 📎 для добавления ассетов с компьютера:
   - ассеты всего проекта;
   - ассеты персонажа;
   - ассеты локации;
   - ассеты сцены;
   - ассеты промтов;
   - ассеты каждого кадра и рендера;
   - ассеты отдельных разделов сценария и структуры.

2. Новый раздел «Ассеты» в левом меню:
   - библиотека всех файлов проекта;
   - поиск по названию;
   - фильтр: изображения, видео, аудио, документы, другие файлы;
   - просмотр, скачивание и удаление;
   - отображение, к чему прикреплён каждый файл.

3. Поддерживаются:
   - изображения;
   - видео;
   - аудио;
   - PDF;
   - TXT, MD, JSON, CSV, SRT, VTT;
   - документы и другие файлы.

4. Файлы сохраняются в IndexedDB браузера, а не в обычном localStorage.
   Это позволяет хранить фото, видео и аудио значительно большего размера.
   Максимальный размер одного файла в прототипе: 300 МБ.

5. Первое прикреплённое изображение автоматически используется как превью:
   - персонажа;
   - локации;
   - проекта в переключателе проектов.

6. Улучшена компоновка:
   - правая панель помощника стала шире;
   - её можно скрыть кнопкой «Помощник» сверху;
   - командная строка остаётся видимой снизу;
   - промты стали выше;
   - интерфейс лучше использует широкий экран.

Установка
---------
1. Останови старый START_PREVIEW.bat.
2. В папке сайта удали старую папку gromvex-studio.
3. Из этого патча скопируй новую папку gromvex-studio в корень сайта рядом с index.html.
4. Замени START_PREVIEW.bat новым файлом из патча либо оставь прежний, если он уже работает.
5. Запусти START_PREVIEW.bat.
6. Открой:
   http://127.0.0.1:8080/gromvex-studio/

Старые проекты
--------------
Данные v02 автоматически загружаются в v03. Удалять localStorage или очищать браузер не нужно.

Важно
-----
Пока это локальный прототип. Ассеты хранятся только в том браузере и на том компьютере,
где они были добавлены. После подключения серверного кабинета файлы будут переноситься
в серверное хранилище и станут доступны после входа по разрешённому email.
