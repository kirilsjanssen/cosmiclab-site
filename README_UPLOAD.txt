======================

Как ставить локально:
1. Распакуй zip.
2. Скопируй файлы в:
   C:\Users\Dirty\OneDrive\Documents\sait
3. Папку assets полностью можно НЕ заменять, если у тебя уже есть:
   assets/cosmiclab_logo.png
   assets/space_bg.jpg
   assets/hero_chart.png
4. Обязательно замени:
   index.html
   styles.css
   app.js
5. Скопируй новые страницы услуг:
   android-app-development.html
   ai-app-development.html

   tradingview-indicators.html
   mt5-mql5-indicators.html
