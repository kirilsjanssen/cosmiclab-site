GROMVEX AI MOVIE STUDIO — PATCH v01
====================================

ЧТО ЭТО
-------
Первый отдельный рабочий прототип помощника для создания фильма.
Он пока НЕ подключён к кабинету и НЕ меняет действующий сайт.
Это сделано специально: сначала проверяем саму студию, потом подключаем её к защищённому кабинету.

ФАЙЛЫ
-----
gromvex-studio/index.html
gromvex-studio/studio.css
gromvex-studio/studio.js
gromvex-studio/assets/gromvex-logo.png

КАК ОТКРЫТЬ НА WINDOWS
----------------------
Вариант 1:
Открой папку gromvex-studio и дважды нажми index.html.

Вариант 2 — через локальный сервер:
1. Открой CMD внутри папки PATCH.
2. Выполни:
   python -m http.server 8080
3. В браузере открой:
   http://127.0.0.1:8080/gromvex-studio/

КАК ПРОВЕРИТЬ НА САЙТЕ БЕЗ ПОДКЛЮЧЕНИЯ К КАБИНЕТУ
--------------------------------------------------
Загрузи папку gromvex-studio в корень сайта.
Тестовая ссылка будет:
https://cosmiclabindicators.com/gromvex-studio/

ЧТО УЖЕ РАБОТАЕТ
----------------
- создание нескольких проектов;
- переключение между проектами;
- обзор проекта;
- синопсис и логлайн;
- библия мира;
- трёхактная структура;
- редактор сценария;
- персонажи и локации;
- сцены и выбор активной сцены;
- режимы: сценарист, режиссёр, оператор, монтажёр;
- заметки камеры и света;
- локальная генерация структурированных промтов для Seedance, Kling и Luma;
- разбивка сцены на 8 кадров;
- черновой сториборд;
- экспорт проекта в Markdown;
- экспорт резервной копии в JSON;
- экспорт шотлиста в CSV;
- автоматическое сохранение в localStorage браузера;
- адаптация интерфейса под меньшие экраны.

ВАЖНО
-----
В v01 настоящий ИИ API ещё не подключён. Кнопки помощника используют локальные шаблоны.
Данные сохраняются только в браузере. Удаление данных браузера удалит локальные проекты,
поэтому для резервной копии используется экспорт JSON.
