GROMVEX AI MOVIE STUDIO — PATCH v04
=====================================

ЧТО ИЗМЕНЕНО

1. Все кнопки прикрепления ассетов переделаны в компактные круглые скрепки.
2. Скрепки больше не растягивают карточки персонажей, сцен и промтов.
3. Убраны отдельные серые кнопки, которые появлялись под карточками.
4. Скрепка располагается в правом верхнем углу карточки или аккуратно в заголовке блока.
5. При наведении появляется подсказка «Прикрепить ассет».
6. После загрузки возле скрепки показывается счётчик файлов.
7. Нажатие на скрепку открывает список уже прикреплённых файлов и загрузку новых.
8. Первое прикреплённое изображение используется как превью:
   - персонажа;
   - локации;
   - сцены;
   - промта;
   - кадра сториборда;
   - карточки рендера.
9. На верхних кнопках ассетов проекта и активной сцены также показывается количество файлов.
10. Данные и ассеты из v03 сохраняются: база IndexedDB оставлена совместимой.
11. Исправлен технический дефект форматирования дополнительного CSS из v03.

УСТАНОВКА

1. Закрой старое окно START_PREVIEW.bat.
2. Удали старую папку gromvex-studio из корня локальной папки сайта.
3. Скопируй папку gromvex-studio из этого патча в корень сайта рядом с index.html.
4. Замени START_PREVIEW.bat новым файлом из патча.
5. Запусти START_PREVIEW.bat.
6. Открой http://127.0.0.1:8080/gromvex-studio/
7. Если браузер показывает старую версию, нажми Ctrl+F5.

ВАЖНО

Ассеты пока сохраняются локально в IndexedDB текущего браузера. После подключения серверного кабинета они будут храниться на сервере и будут доступны после входа с другого устройства.
