How it works

Simple workflow for daily work documentation and customer reports.
1
Create an object
Add a project, client, place, work period, area in m²/ha and optional GPS/location data.
2
Add photos & markings
Take photos, import images, mark the plan/map and write short notes under photos.
3
Export and share
Create a clean report and share it via WhatsApp, email, cloud apps or other Android share targets.

Local-first privacy

PhotoReport is designed to work locally on the phone. There is no forced account and no automatic cloud upload for local report functions. Camera, gallery and location access are used only for the selected app functions. Sharing happens only when the user chooses the Android share menu.
