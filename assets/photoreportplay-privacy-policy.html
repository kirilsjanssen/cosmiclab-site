PhotoReport – Privacy Policy

This Privacy Policy explains how the public Google Play version of PhotoReport handles information on the device.

App: PhotoReport Developer: CosmicLab Indicators Website: cosmiclabindicators.com Effective date: 28.06.2026

1. Controller / Contact

Developer: CosmicLab Indicators
Website: https://cosmiclabindicators.com/
Contact: cosmiclab.support@gmail.com

2. What PhotoReport is for

PhotoReport is an Android app for outdoor photo reports and work documentation. It can be used to create objects, add work and problem photos, attach comments, mark plans or map images, save work status data and generate report files.

3. Local-first use

PhotoReport is designed to work locally on the device for its core functions. The app does not require a mandatory server account for the normal local reporting workflow.

4. Information stored locally on the device

Depending on how the app is used, the following data may be stored locally on the device:

  • Object names, project names and user-entered notes
  • Status information, dates, work period data and area values
  • Photos captured with the camera or selected from the gallery
  • Marked copies of plans, maps or photos
  • Location/GPS information, if the user chooses to use this feature
  • Exported reports saved as image or PDF files

5. Permissions

PhotoReport may request the following permissions when relevant features are used:

  • Camera – to capture work or problem photos
  • Photos / Media / Gallery – to select images from the device
  • Location – to attach GPS/location data to a report if the user uses this function

These permissions are used only for the corresponding report functions inside the app.

6. No automatic upload for the base local version

PhotoReport does not automatically send work data, photos, GPS data or reports to CosmicLab Indicators as part of the base local workflow. Data remains on the device unless the user intentionally shares or exports it.

If the user manually shares a report or image through WhatsApp, email, Google Drive or another third-party app, the privacy terms of that third-party service will also apply.

7. In-app purchases / subscriptions

Monetization may be added in the future for public release plans such as yearly subscription options. If such features are activated later, this page may be updated accordingly.

8. Data deletion

Because the app mainly works locally, the user can delete objects, reports, app data or uninstall the app from the device. Additional data deletion information can be provided on the support website if needed.

9. Children

PhotoReport is a work and documentation tool and is not intended for children.

10. Changes to this Privacy Policy

This Privacy Policy may be updated if the app functions or legal requirements change. The latest version will be published on the developer website.
